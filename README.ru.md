# Subtitle Edit Classic

Форк [официальной классической ветки Subtitle Edit 4.x](https://github.com/SubtitleEdit/subtitleedit/tree/se4-legacy), сохраняющий интерфейс Windows Forms.

## Установка

Скачайте файл `SubtitleEdit-Classic-<версия>-Setup.exe` из раздела Releases. Это обычный установщик Windows: он устанавливает приложение, создаёт выбранные ярлыки и добавляет возможность удаления. Установщик использует отдельное имя приложения и каталог Subtitle Edit Classic; им можно обновить предыдущую версию этого форка.

Приложению требуется .NET Framework 4.8. Настройте или скачайте FFmpeg, когда программа предложит это сделать. Встроенные переводы, включая русский, совместимы с классической схемой 4.0.16 независимо от номера версии форка.

Описания релизов и changelog ведутся на английском. Эта страница — отдельная русская документация проекта.

## Основа проекта

Основа — официальная ветка `se4-legacy`, коммит `96e6d302659e94e77564b98805d37e52c80d6501` от 10 октября 2026 года. Он включает 22 коммита после последней стабильной версии оригинальной ветки 4.x — 4.0.16. Основная ветка форка также называется `se4-legacy`.

Редактор, классические панели и инструменты работы с субтитрами сохранены. Номера 4.0.17 и выше в этом репозитории относятся к релизам форка, а не к официальным релизам Subtitle Edit. Возможности из 5.x переносятся выборочно, без перехода на её интерфейс.

## Classic 4.0.21: OCR видео и локальная озвучка

Извлечение вшитых субтитров доступно через **Видео > OCR вшитых субтитров**: Paddle OCR или CrispEmbed (GLM-OCR, DeepSeek-OCR-2, PP-OCRv6). Выбери область, проверь кадр, отредактируй найденные реплики и перенеси их в классический редактор. Из стабильной v5.2.0 перенесены группировка, объединение повторов и уточнение таймингов по кадрам. Включены английские/русские таблицы исправлений; движки и модели скачиваются из окна.

В классической озвучке появился **Qwen3 TTS (CrispASR)**: девять готовых голосов CustomVoice и клонирование по импортированному образцу Voice clone. Выбери фрагмент аудио/видео, укажи его точный текст и подтверди разрешение на использование голоса. Запись преобразуется в WAV 24 кГц, моно. Несовпадающий текст может приводить к посторонним фразам или невнятной речи — расшифровка должна соответствовать выбранной записи.

Перед генерацией выбирается готовый WAV или видео с озвучкой. Папка назначения запоминается; готовый результат сохраняется туда, временные рендеры очищаются. Модели и повторно используемые образцы голосов остаются в каталоге данных приложения.

Также исправлены прокрутка параметров OCR, обрезанные кнопки выбора области и координаты эффектов движения при хардсабе ASS. Распознавание речи, классические панели и исправление MP4 для Audition сохранены.

Проверены русский/английский OCR и TTS, реальное видео с хардсабом, отмена нативных процессов, сборка дорожки по таймингам, замена экспортируемого файла и очистка временных рендеров. Клонирование проверялось на разрешённом синтетическом образце; сходство на произвольной записи не гарантируется. Полный набор OCR/AI/TTS из v5 и автоматическое клонирование каждого диктора пока не перенесены.
## Распознавание речи в 4.0.20

В классическое окно добавлены локальные движки:

- **Crisp ASR:** GigaAM, Parakeet и Qwen3.
- **Qwen3 ASR CPP** с моделью выравнивания таймингов.
- **Whisper CPP Vulkan**.
- **Standalone WhisperX** в режиме CPU.

Выберите движок и модель, затем нажмите кнопку скачивания возле списка моделей или начните распознавание. Программа скачает необходимые движок и модель. WhisperX загружает свои модели при первом запуске. Новые автономные движки не требуют отдельной установки Python.

В зависимости от движка доступны CPU, CPU legacy, Vulkan и CUDA 13. Большие модели не включены в установщик; скачанные файлы сохраняются в отдельном кэше приложения.

Crisp ASR разбивает непрерывную речь на субтитры по словам и предложениям, используя тайминги движка. VAD дополнительно выделяет участки речи по паузам; при пустом результате можно включить повтор без VAD. Доступны отчёт о проблемных строках, необязательное удаление повторов и звуковых описаний, прогресс, время выполнения и отмена с завершением дочерних процессов.

Пакетное распознавание сохраняет новые SRT под уникальными именами и не перезаписывает существующие субтитры. Исправлена прокрутка при переходе от короткого списка моделей к длинному, включая выбор последней модели колесом мыши.

**Известное ограничение:** при проверке сервер русской модели пословного выравнивания WhisperX возвращал HTTP 500. Для русского WhisperX можно отключить уточнение таймингов по словам и использовать тайминги фраз. Английское выравнивание проверено. Отдельное старое окно распознавания выделенных строк и платные облачные сервисы на новые движки пока не перенесены.

Проверены русский и английский, работа на NVIDIA, VAD, запуск через окно программы, отмена и пакетное сохранение. На двухминутном фрагменте видео без VAD после постобработки получено 29 субтитров с максимальной длительностью 7,2 секунды; распознанные слова сохранены. CI проверяет чистое скачивание CPU-движка и модели и реальное распознавание после установки Setup.exe. Эти проверки не гарантируют точность каждой модели на любой записи; отчёт о проблемных строках проверяет структуру и тайминги, а не правильность распознанных слов.

## Хардсаб и изменение размера окна в 4.0.19

Окно создания видео с наложенными субтитрами поддерживает совместимые сочетания контейнеров **MP4, MKV, MOV, TS, WebM** и аудио **AAC, AC-3, MP3, Opus, Vorbis** либо копирование исходной аудиодорожки.

В отдельном классическом окне «Дополнительно» доступны оформление текста и эффекты, PNG-логотип, наложение Blu-ray SUP, создание видео из аудиовхода и двухпроходное кодирование с расчётом размера по исходному файлу. Исходные ASS-стили сохраняются.

Исправлены перекрытия прогресса и нижних кнопок; ручной размер файла задаётся в целых МБ. При растягивании редактора уменьшено количество промежуточных изменений размеров, а ширина и высота видеопанели применяются вместе.

Проверены 24 сочетания аудио и контейнеров, основные сценарии экспорта, тайминги MP4, наложения, аудиовход, два прохода, шесть компоновок редактора и выбор языка после установки. Изменение размера проверялось с H.264-видео и загруженной осциллограммой; универсальная плавность на всех видеокартах и дисплеях не гарантируется.

## Исправление MP4/AAC для Adobe Audition

Экспорт хардсаба включает MP4 edit lists: `-use_editlist 1` вместо их отключения. Это позволяет учитывать задержку AAC-кодера без растягивания первого видеосэмпла.

В исследованных H.264/AAC-файлах с частотой 23,976 кадра/с отключение edit lists давало первый сэмпл длительностью 1513 тиков вместо 1001 при базе времени 1/24000. Исправление таймингов восстановило воспроизведение в Audition без изменения сжатых данных H.264 и AAC. Подробности приведены в [issue оригинального проекта #15992](https://github.com/SubtitleEdit/subtitleedit/issues/15992).

Исправление включено при экспорте MP4/MOV. Ранее созданные файлы необходимо экспортировать заново или исправлять отдельно: установка программы их не меняет. Полный новый экспорт стоит проверить в Audition на ранее проблемных местах.

## Сборка из исходников

В Windows откройте Developer PowerShell для Visual Studio. Нужны .NET SDK 8 и targeting packs .NET Framework 4.8/4.8.1:

```powershell
msbuild src/UpdateAssemblyInfo/UpdateAssemblyInfo.csproj /restore /p:Configuration=Release
& ./src/UpdateAssemblyInfo/bin/Release/net48/win-x64/UpdateAssemblyInfo.exe src/ui/Properties/AssemblyInfo.cs.template src/libse/Properties/AssemblyInfo.cs.template
msbuild SubtitleEdit.sln /restore /p:Configuration=Release /p:SolutionDir="$PWD\"
```

Для обычного установщика нужен Inno Setup 6.2.1 или новее:

```powershell
ISCC.exe /DCLASSIC_FORK installer/Subtitle_Edit_installer.iss
```

Ключ `CLASSIC_FORK` задаёт отдельную идентичность приложения, каталог установки и ярлыки.
