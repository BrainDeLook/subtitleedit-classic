# Subtitle Edit Classic changelog

## 4.0.25 — local preview

- Ported the stable v5.3 selected-lines ASR workflow to the classic speech window. Modern Crisp ASR, Qwen3 ASR CPP, Whisper CPP Vulkan and standalone WhisperX are available alongside legacy Whisper choices. Selected lines keep their existing timing, actor/style metadata and identity; only explicitly applied successful text is changed. Unselected and failed lines remain untouched, including the original-text column.
- Added per-line result/error status, Apply transcribed lines and Retry failed lines. Successful results survive other clips failing, empty transcripts and cancellation; retry excludes completed clips. Each attempt uses an isolated job directory, preventing stale transcripts from being read on retries. A single long clip can still use the explicit context-menu command for segmentation with new timings. Already-demuxed clips use their own first audio stream instead of the video's stream index.
- Validated partial failures, retries, empty results, cancellation, metadata retention, classic layout and real Russian/English Parakeet CUDA 13 transcription. Paid API validation continues to use local protocol tests without paid requests.

- Added a selected-clip waveform to classic speech review, with subtitle timeline labels, overrun coloring, draggable start/end boundaries, zoom/scroll and MPV playback from the clicked audio position. Moving the start shifts the cue and generated clip together; changing the end never trims or stretches the audio.
- Added Fit end to audio and Reset timing, matching stable v5.3 behavior. Fit uses the actual generated clip duration after speed adjustment; reset restores both times captured when review opened. Timing changes are retained in session exports and used by final audio assembly. Waveform loading runs in the background and cancels safely when switching rows or closing review.

- Added portable speech sessions using the stable v5.3 `SubtitleEditTts.json` schema plus Classic cue metadata. Export stores audio and clone references alongside the JSON in the chosen folder; engine/model/voice/instruction, timing, inclusion flags, actors and ASS metadata survive import. Unselected and original-only cues remain on the timeline. Credentials and provider secrets are never exported.
- Imported sessions can be reviewed and assembled from their saved audio without synthesizing every line again. Individual regeneration uses the saved per-line engine and voice, including distinct settings for lines sharing an actor. Session-specific casts do not overwrite the default cast. Imported reference copies are removed when the speech window closes; their portable originals remain in the session folder.
- Added current-review take history, including intermediate successful regenerations. Previous audio, text, voice, model/instructions and speed can be previewed and restored. History is intentionally not included in session exports, matching stable v5.3.
- Session export commits metadata only after assets are copied, preserves previous exports on failure/cancellation and avoids overwriting files still used by takes. Import validates assets and relative paths. Tests cover moving the folder, clone-reference cleanup, unchecked actors, ASS metadata, assembly without synthesis, restored regeneration and classic toolbar bounds. Fixed online-engine buttons being clipped when imported actors expand the window.


- Completed the enabled stable v5.3.0 Windows TTS catalog with Edge TTS, Mistral Speech, Google Cloud Speech and Zonos (CrispASR). An automated audit checks all 30 enabled implementations; legacy extras and experimental F5 remain separate. Removed a duplicate Tortoise selector entry.
- Added classic settings, voice refresh, actor assignment, regeneration, live playback, cancellation and WAV normalization for the three online engines. Edge installs edge-tts 7.3.1 in an isolated Python environment and exposes rate/pitch/volume. Mistral stores its API key encrypted for the current Windows user. Google authenticates using a service-account JSON file and caches OAuth tokens; three-letter language tags are preserved. Failed refreshes retain the previous voice catalog; provider errors do not expose response bodies.
- Added verified Zonos Q8/DAC models and automatic local extraction of the pinned official eSpeak NG 1.52.0 package, with its GPL license/source notice. No Windows MSI installation or custom actions are executed. The backend offers one fixed voice, no cloning, and restarts on target-language changes. The shared local catalog now has 20 engines and 51 bundles.
- Validation: real Edge installation, voice discovery, English/Russian synthesis and cancellation; real Zonos English/Japanese synthesis, language changes and cancellation. Independent ASR recovered the English Zonos and both Edge test sentences. Google/Mistral authorization, request/response handling and audio normalization passed simulated HTTP tests; paid live synthesis was not tested. Classic settings/layout, all-30 catalog coverage and the existing media/speech regressions passed.


- Added the remaining requested stable v5.3 local TTS engines: Kokoro, experimental F5-TTS, Pocket TTS, VibeVoice, IndexTTS 1.5 (CrispASR), Dots-TTS, Confucius4, MOSS-TTS and both OmniVoice runtimes. The shared local catalog had 19 engines and 50 pinned model bundles after that addition. Kokoro and standalone OmniVoice install their exact upstream-pinned Windows runtimes with SHA-256 verification.
- Adapted per-engine startup/request protocols, reference sample rates, language checkpoints, companion models, Confucius/Dots ODE steps and standalone OmniVoice Default-voice instructions to classic forms. Standalone text is delivered through UTF-8 stdin; generated files use the existing output/review path. Preset-only engines ignore per-line cloning references.
- Compatible cloning engines accept reference recordings without a transcript. The voice manager, trimming and ZIP import/export preserve those references; engines requiring transcripts filter them out and retain strict validation. Voice permission checks remain in place.

- Fixed live TTS playback stopping immediately after MPV loaded a speech clip. Playback now waits for the file-loaded pause to finish before starting speech; native checks verify actual position advancement, repeated clips and pause/resume.

- Added Fish Audio S2 Pro, IndexTTS 2.5, Higgs Audio v3, FireRedTTS3, KugelAudio and Breeze TTS 2 from stable v5.3.0. Their shared audio.cpp runtime offers CPU, Vulkan and CUDA builds with pinned archive checksums; twelve model choices download on demand with size/SHA-256 checks. Existing classic voice references, actor casts, review and export are reused. Fish/Higgs/Index/Breeze retain their separate first-download license acceptance.
- IndexTTS exposes its supported language choices, emotion and duration control. FireRed uses the mandatory language tag, exact reference transcript and clone task. Higgs/FireRed reference copies receive the stable fade/silence-tail preparation. Kugel is preset-only; Breeze offers English/Chinese presets/design instructions and reference cloning.
- Speech settings remain open while selecting or editing subtitles in the main editor. Playback starts at the live selection, unchanged preparation refreshes from main-window edits, and conflicting preparation changes cannot overwrite newer edits. Closing cancels active speech work and waits for cleanup.
- Play with speech from the selected main-window line, using the current engine or actor cast. Three-line lookahead follows the video, with pause/resume, seek handling, volume ducking, capped speed-up and waiting for delayed speech. Temporary clips and owned engines are cleaned up on stop.
- Ported the stable nOCR matcher: best candidate selection, exact-size indexing, content/parameter-aware match caches with mutation invalidation, expanded-glyph neighbour checks, small-glyph safeguards, italic retry and Cyrillic case/composition handling. The classic bitmap adapter retains V2 database compatibility and adapts relative word-spacing/baseline detection.
- nOCR training uses the stable font trainer and discriminative glyph lines, with Random, SkeletonDistance and EdgeHough choices in the classic training/character windows. Train from subtitle text or a custom character set, with merged combinations, bold/italic and cancellation. Saving a database keeps a previous-file backup.

Native checks additionally cover the default model of all ten remaining catalog additions on Windows/NVIDIA: English synthesis, cancellation and output cleanup; Russian synthesis with reference switching for Confucius, MOSS and both OmniVoice runtimes; OmniVoice Default-voice switching and standalone whisper instructions. Kokoro used its CPU runtime, standalone OmniVoice used CUDA and the other added engines used the shared CrispASR CUDA 13 runtime. Real mixed OmniVoice/Pocket actor generation preserves unchecked actors. Protocol/layout checks cover all 50 model bundles, companion staging, UTF-8 stdin and transcript-free voice-pack round trips. Other quantizations and compute variants have narrower native coverage. F5 remains experimental and slow; Russian is not supported by every model.

Native CUDA checks cover all six new default TTS models. Independent ASR recovered the English test sentence from all six and Russian from Fish, Higgs, Kugel and FireRed with a Russian reference. FireRed cross-language cloning was poor with an English reference; prefer a same-language reference. IndexTTS does not advertise Russian; Breeze supports English/Chinese. Other quantizations/backends have narrower native coverage. Fifty adapted stable nOCR cases and separate Russian/English training round trips passed. Playback checks include real muted MPV clip transitions and scheduling/cancellation tests. This preview remains local; no release has been published.

## 4.0.24

- Speech recognition: selectable Silero, FireRedVAD, Whisper-VAD and WebRTC; optional Mel-Band RoFormer speech isolation; Sortformer speaker detection in the ordinary ASR window. Crisp-only flags stay disabled for other runtimes. Postprocessing and duplicate removal respect speaker changes; diarized batch output uses ASS to retain actors.
- Added stable v5.3 Parakeet Ultra, Phonon-2 and additional Japanese Parakeet/Reazon models, Voxtral F16 and Index-Echo with its matching decoder. New model bundles carry pinned sizes and SHA-256 hashes. Phonon-2 is English-only; Index-Echo translates Chinese speech into English, Japanese or Spanish, preserving bilingual cue timing while discarding the original-language line.
- Time-code review now contains synchronized original/proposed waveforms. Drag cue boundaries or whole cues, zoom, listen and reset a selected cue. Manual edits mark the cue for selective application; source time codes remain unchanged until Apply, with the existing main-window undo path retained.
- Added twelve language-specific wav2vec2 forced aligners alongside Canary/Qwen. Language-aware ordering and guards avoid selecting an aligner for the wrong language. Speech checks prefer an installed Parakeet Ultra model when available.
- Validation includes native CUDA 13 Russian/English ASR, all four VAD families, ordinary Sortformer labels, speech isolation, English Phonon/Voxtral, Chinese-to-English Index-Echo, English wav2vec2 and Russian Canary alignment. Waveform tests cover repeated mouse moves, grid synchronization, invalid ranges and selective application. Other quantizations and languages have narrower native coverage; diarization can still merge speakers and separation can leave artifacts.

This stable release includes the normal Windows installer and preserves the classic Windows Forms interface. Engines and model weights download on demand.

## 4.0.23

- Added CosyVoice 3, VoxCPM 2 and Chatterbox from stable v5.3.0. Ten model choices include CosyVoice RL variants and Chatterbox Base/F16/Q4_K/Turbo. Model bundles download through the classic interface with pinned sizes and SHA-256 checks; all CosyVoice companion files are staged together.
- These engines share the reference-voice library, support actor-specific casts and audio-review regeneration, and can use original subtitle references for per-line cloning. CosyVoice also exposes eight presets. Chatterbox Turbo is restricted to English; VoxCPM infers the language from text. Compute, model, reference language and voice preferences persist separately for each engine.
- Native CUDA 13 checks covered Russian and English synthesis with the default model of all three engines, CosyVoice preset switching and cancellation. Independent GigaAM/Parakeet checks recovered all six test sentences. Mixed casts with Supertonic and actor-specific regeneration passed for all three engines; VoxCPM per-line cloning and temporary-reference cleanup passed. Other model quantizations and compute variants have not received the same native coverage.
- Fixed burn-in quality hints overlapping the CQ input and moved the total-bitrate explanation into its own bounded row.
- Cast settings persist each actor's engine, voice, model, language and instructions. Qwen3/Supertonic/API casts can be mixed with the existing engines; audio review regenerates each actor through the correct engine. Voice-name tags can be moved into speech-session actor metadata without removing them from the editor text.
- Clone voices from video using Sortformer speaker labels or existing subtitle actors. Review actor names and exact reference transcripts before importing. Per-line Qwen3 cloning uses original-language subtitle text, with temporary references cleaned after synthesis.
- Voice manager: edit names/transcripts, trim a reference into a new copy, import/export voice packs, copy references to another engine's folder and download the stable upstream voice packs. Attribution is retained where supplied.
- Qwen3 VoiceDesign and Sidon reference restoration use the stable v5.3 model/runtime definitions, validated downloads and cancellable local processing.

Native checks covered mixed Qwen3/Supertonic casts, actor-specific regeneration/cancellation, Russian/English VoiceDesign, cross-language per-line cloning, Sidon CPU restoration and an official English voice-pack download/import. Independent ASR recovered the generated test sentences. Sortformer ran successfully but merged two short synthetic voices into one in the test fixture; automatic speaker results require review. Existing subtitle actors offer a direct alternative. Paid cloud-provider synthesis was not exercised.

This stable release preserves the classic Windows Forms interface and includes the normal Windows installer. Engines and model weights download on demand; large model files are not bundled with the installer.

## 4.0.22

Feature ports are based on the stable upstream v5.3.0 tag. This release preserves the classic Windows Forms interface.

- Burn-in: half side-by-side / top-bottom 3D subtitles with depth adjustment and a rendered preview; current NVENC presets and migration of legacy low-latency/lossless presets. The ordinary player does not composite 3D overlays: use the Preview button.
- Speech generation: Supertonic-3 with ten preset voices, 31 languages and speed control; OpenAI-compatible TTS for OpenAI, OpenRouter or a custom endpoint, separate provider settings, MP3/PCM fallback and protected API-key storage on Windows.
- Prepare speech: review continuation merges and silence-only annotations before generation. Actor changes, dialogue dashes and long pauses prevent merges. Annotation text remains in the subtitles; editor changes can be undone.
- Fixed the Russian pixel-format dropdown extending outside the burn-in video column.
- Actor selection: explicit checkboxes limit synthesis and audio review to the selected actors. In selective removal mode, unselected and unnamed actors retain their original audio in video exports. Speech removal is restricted to generated cue intervals, with short internal fades; overlapping unselected actor intervals remain original because timing alone cannot separate simultaneous voices.
- Selective dubbing supports the newer FFmpeg file-argument syntax, with a fallback for older builds.
- Dubbing settings now offer a persisted choice between removing all original speech and removing only selected actors' generated cue intervals. Actor selection for synthesis remains independent; existing settings retain selective removal.
- Dubbing: remove original speech with HTDemucs or Mel-Band RoFormer and mix the remaining music/effects with generated speech. Models download on first use. Video muxing remains cancellable; MP4 uses AAC by default and preserves edit-list timing.
- Improve time codes: Canary/Qwen forced alignment, independent Parakeet word checks, rough synchronization, neighbouring-line safeguards, editable old/new proposals, selective application and optional frame snapping. Preview proposed positions in the main player. Positioned signs, comments and music cues are excluded from speech alignment.
- OCR: Find/Replace with regular expressions, whole-word search and undo; stable upstream CrispEmbed builds (CPU 0.17.12, GPU 0.17.11), Romanian/Croatian correction rules and the Cyrillic nOCR database. nOCR optimization uses the v5.3 pruning algorithm with the classic bitmap/line adapters, previews the reduction and backs up the original file.
- Retained the local speech-ending fix: relative silence thresholds and no unconditional 100 ms cuts from either end.

Validation covers real Russian/English Supertonic and Qwen synthesis, permitted synthetic-reference cloning, independent ASR checks, both native speech-removal models, real forced alignment, 3D/NVENC exports, API protocol/PCM/cancellation tests without paid requests, OCR/nOCR algorithms and classic forms. On the compressed Russian movie crop, GLM made the same spelling errors as the old runtime; this update does not guarantee error-free recognition. Separation can leave residual voices or remove parts of the background; long CPU jobs can be slow.

The full v5 catalog, voice-pack manager, Sidon reference cleaning and automatic per-line voice cloning are not included in this release.

## 4.0.21

Subtitle Edit Classic 4.0.21 brings video OCR and Qwen3 speech generation from stable Subtitle Edit 5.2.0 into the classic Windows Forms interface.

- Extract burned-in subtitles with Paddle OCR or CrispEmbed: GLM-OCR, DeepSeek-OCR-2 and PP-OCRv6. Includes crop selection, frame testing, editable cues, grouping, timing refinement and English/Russian OCR correction tables.
- Generate local speech with Qwen3 TTS CustomVoice or Voice clone. Nine preset speakers, explicit language selection, imported audio/video references, reference normalization and matching transcripts are supported. Engines and models can be downloaded from the interface.
- Choose the destination for the finished WAV or dubbed video before generation. The folder is remembered; temporary render jobs are cleaned up after completion or cancellation.
- Fixed OCR scrolling and clipped crop buttons. Fixed ASS burn-in motion effects moving text outside the script canvas when the video and ASS resolutions differ.
- Preserved existing speech recognition, classic panels, hard-subtitle features and the MP4/AAC timing fix for Adobe Audition.

Validation includes Russian/English OCR and TTS, native process cancellation, timed audio mixing, export replacement and cleanup, and an actual burned-in video sample. Independent speech recognition confirmed generated test sentences. Installer CI checks startup, packaged translations, speech/model scrolling, a clean ASR engine download, OCR algorithms/layout, TTS layout/export and the ASS canvas regression.

For cloning, the transcript must exactly match the selected reference recording. Use a clear single-speaker sample and confirm permission in the import dialog. Cloning validation used a permitted synthetic reference; voice similarity on arbitrary recordings is not guaranteed. Automatic per-line speaker cloning, VoiceDesign and the full v5 engine catalog are not included. The existing Russian WhisperX external-alignment limitation remains: disable word alignment when its provider is unavailable.

Download **SubtitleEdit-Classic-4.0.21-Setup.exe**, the normal Windows installer. Large OCR/TTS/ASR models are downloaded separately and are not bundled. SHA256SUMS.txt contains the installer checksum.
