# Локальная сборка Classic 4.0.28.58: установка и общая проверка

Это один локальный пакет с дополнениями по всем 33 замечаниям сверки с 5.4.0 и результатами семи отдельных проверок. Классические окна, кнопки и группировка меню сохранены. Публикации на GitHub нет. Модели и тестовые видео в пакет не входят; установленная ранее программа автоматически не заменяется.

## Установка

1. Распакуйте ZIP в обычную доступную для записи папку. Сохраните субтитры и закройте Subtitle Edit Classic.
2. Откройте PowerShell **от имени администратора**, перейдите в распакованную папку и выполните:

   ```powershell
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install-Classic54.ps1
   ```

   При нестандартном расположении добавьте `-InstallDirectory 'D:\Apps\Subtitle Edit Classic'`.
3. Дождитесь сообщения `Installed local Classic 4.0.28.58`. Запустите программу обычным ярлыком; проверьте версию через **Помощь → О программе**.

Установщик проверяет SHA-256 каждого нового файла, сохраняет прежние EXE/DLL в указанную в результате папку `backup-…`, проверяет версию и неизменность Settings.xml. При ошибке замены откатывает файлы. AppData, словари и скачанные модели не удаляются. Это обновление существующей Classic 4.0.28, а не установщик с нуля. Отчёт установки лежит рядом со скриптом в `installation-….result.json`.

## Новые быстрые кнопки — 4.0.28.58

На верхней панели, между привычными кнопками и выбором формата, появились: **OCR вшитых субтитров, распознавание речи, озвучка, перевод, улучшение таймингов, ASS Draw, хардсаб и пакетная конвертация**. Если старая кнопка хардсаба уже включена, второй такой же кнопки не будет.

1. Запустите Classic и наведите курсор на новые значки — подсказки показывают полные названия.
2. Нажмите OCR: должно открыться обычное окно OCR вшитых субтитров. Остальные кнопки открывают те же команды, что и меню.
3. Откройте ASS с репликами: станут доступны перевод, озвучка и ASS Draw. Для улучшения таймингов также загрузите видео/аудио.
4. **ПКМ по верхней панели → Быстрые кнопки функций**: снимите отметку с ненужной команды. После перезапуска выбор сохранится.
5. При уменьшении окна не поместившиеся элементы доступны через стандартное меню переполнения справа на панели.

## Что проверить в интеграции 5.4 в целом

Все проверки выполняются после одной установки. Начните с привычного проекта; для OCR можно пропустить пункт, если растровых субтитров нет.

| № | Где и что сделать | Что должно получиться |
| --- | --- | --- |
| 1 | **Параметры → Дополнительные параметры редактора…**. Уменьшить окно, прокрутить до конца. При желании проверить с крупным системным шрифтом | Подписи переносятся, «Сохранить» и «Отмена» доступны. Здесь же появились шрифт второго субтитра и сочетания сдвига выбранных / выбранных и следующих / всех строк на кадр |
| 2 | Открыть видео и **Видео → Открыть второй (вспомогательный) файл субтитров…**. Выбрать шрифт в дополнительных параметрах. Проверить видео с ненулевым смещением, если такое используете | Вторые субтитры отображаются своим шрифтом и учитывают подходящее смещение; исходный файл не переписывается |
| 3 | В ASS открыть команды **Установить фон**, **Прогресс-бар**, **ASS Draw**, **Установить позицию** в группе ASS/SSA | У фона 24 варианта, у полосы 18. В Draw проверить Ctrl+клик, выделение рамкой, стрелки, Delete и Undo. В позиции используется кадр основного плеера; дополнительный mpv не открывается |
| 4 | **Инструменты → Пакетное преобразование…**. На копии SRT включить смену FPS 24→25 и выбрать MicroDVD; подвигать разделитель областей | Выход использует 25 FPS без повторного сдвига времени. Разделитель меняет размеры списка файлов и функций. Отключённая смена FPS ничего не меняет |
| 5 | В переводе открыть **Дополнительно**, включить **Не переводить реплики с музыкальными символами**. Проверить `♪ Песня ♪` и обычную реплику с уже настроенным бесплатным/локальным движком | Музыкальная строка остаётся как была; обычная переводится. В расширенных настройках сервиса доступно обновление списка моделей; смена провайдера сохраняет точный вариант языка, если он поддерживается |
| 6 | **Изменить выбор → С ошибками**; в **Сохранить как…** проверить избранные форматы; в выборе цвета нажать **Из изображения…** | Отбор ошибок работает и для SRT, избранное находится в начале списка, цвет выбирается из картинки |
| 7 | Обычное окно OCR: Ctrl+колесо и Ctrl+0 над изображением; открыть полный просмотр и листать стрелками/кнопками | Масштаб меняется и сбрасывается; соседние картинки показываются в одном окне. Стандартные базы Latin/Cyrillic обновлены автоматически, пользовательское обучение сохранено |
| 8 | В менеджере загрузки словарей проверить наличие **Удалить…**; в **Параметры → Списки слов…** набрать русскую букву и открыть ПКМ | Есть выбор установленного словаря для удаления, личные слова сохраняются; поиск по букве и стандартное удаление из списка работают |
| 9 | Несколько раз быстро выполнить короткий сдвиг видео; проверить предыдущую/следующую реплику и Space в полном экране | Сдвиги суммируются, UI не замирает. Смена позиции и Play/Pause не оставляют старую цель перемотки |
| 10 | **Видео → Открыть видео по ссылке…** | Есть выбор браузера для cookies. Оставьте «Нет», если cookies не нужны; это не требует проверки платных API |

Для проверки исправления буфера: в проекте со смещением видео скопируйте реплику, затем вставьте её обычным способом или через вставку столбцов. Время не должно получать лишнее смещение, даже если смещение видео изменено после копирования.

## Общий проход по функциям

Проверяйте на копиях субтитров и коротких фрагментах. Это один список для всего пакета; промежуточные установки между пунктами не нужны.

| Что | Где и как | Ожидаемый результат |
| --- | --- | --- |
| Обычная работа | Открыть SRT, затем ASS с актёрами; изменить текст, сохранить копию и открыть снова | Текст/тайминги/актёры сохраняются, привычные команды доступны |
| Внешние изменения | **Параметры → Дополнительные параметры редактора…**: выбрать режим внешних изменений. Открытый файл изменить другим редактором | Автоперечитывание только без несохранённых правок либо вопрос согласно режиму; при сохранении нет молчаливой потери чужих изменений |
| Управление видео | Там же включить дополнительные кнопки плеера. Проверить скорость, предыдущую/следующую реплику, CC и полный экран | Управление работает, в полном экране кнопки появляются поверх изображения и скрываются; ПКМ/средняя кнопка не запускают видео |
| Тайминги | В дополнительных параметрах назначить новые сочетания движения на кадр/границ. Переместить две ASS-реплики с одинаковым временем на осциллограмме | Одинаковые интервалы двигаются вместе; длительности сохраняются, Undo возвращает изменение |
| Синхронизация | В меню видео найти **Синхронизировать субтитры со звуком…**; для дорожки — **Синхронизировать аудиодорожку…** в меню видео | Предпросмотр использует выбранную дорожку; при экспорте сдвигается только она. Для проверки подходят известные несколько реплик с постоянным смещением |
| Перевод | В основном списке выделить несколько строк → **ПКМ → Выбранные строки → Перевести выделенные строки… → Перевести с заменой на месте…** → выбрать движок/языки → **Перевести выбранные** → **OK**. Поиск/замена доступен по ПКМ в правом списке окна перевода | Меняются выбранные строки, остальные сохраняются. Отмена не меняет документ; Ctrl+Z возвращает результат. | ASS Draw | Открыть ASS → команда **Редактор ASS Draw…** в группе ASS/SSA | Фигуры/текст/маски/группы, галерея, анимации и сохранение проекта; после применения Undo восстанавливает исходные реплики |

| Закладки/исходник | Список закладок: экспорт/импорт. В исходном тексте изменить реплику и нажать Ctrl+Enter | Закладки восстанавливаются, исходник применяется к списку; изменения отменяются Undo |

Микрофон выключен по умолчанию. Его можно включить в дополнительных параметрах редактора и использовать с уже установленным локальным ASR. Реальная запись голоса в автоматические проверки не входила.

## CLI без платных сервисов

FFmpeg должен быть установлен в настройках Classic или доступен через PATH. Из папки программы:

```powershell
.\seconv.exe 'D:\Test\sample.srt' ass '--output-folder:D:/Test/result' '--burn-in-video:D:\Test\sample.mp4' '--burn-in-effects:fade:120' --json
```

Получаются `sample.ass` и `sample_burn-in.mp4`; размер ASS определяется по видео. Повторный запуск не перезаписывает результат без `--overwrite`. Все параметры: `seconv.exe --help-json`.

Результаты нового прогона и прежних проверок разделены в [отчёте по интеграции](UPSTREAM_5_4_STATUS.md). В него входят проверки данных nOCR, реальных окон, ASS-вывода, протоколов перевода/ASR, пакетного сохранения, AAC, установки и отката в отдельной папке. Платные API, все большие модели, физический DVD, реальная запись с микрофона и установка через настоящий Inno Setup в этот прогон не входили.
