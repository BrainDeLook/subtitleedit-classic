# Проверка версии 4.0.28 с девятью блоками 5.3

Это инструкция для **4.0.28**, включающей изменения локальной 4.0.27.103. Локальная установка использует обычный ярлык Subtitle Edit Classic; переносная копия также находится в подготовленной папке локальной сборки. У переносной сборки отдельные настройки и кэш; существующие скачанные модели не копировались в комплект. Первые проверки не требуют скачивания моделей или оплаты API.

## Проверка новой навигации

1. Открой «Инструменты» и «Видео»: команды собраны в тематические подменю. В «Файл → Импортировать из / Экспортировать в» форматы разбиты по назначению. «Сохранить», «Сохранить как» и сохранение Forced-реплик остаются рядом.
2. Нажми ПКМ по заголовкам таблицы: доступны «Столбцы…», быстрые галочки, отображение тегов/форматирования, шрифт и цвета интерфейса, подсветка ошибок, орфография. Включи «Актёр», Forced или Shot in; проверь те же галочки в «Параметры → Список субтитров». ASS-слой отображается в ASS, настройки сохраняются после перезапуска.
3. Нажми ПКМ по реплике: операции разделения/объединения, форматирование и метаданные находятся в отдельных подменю. «Настройки списка» ведут к тем же параметрам таблицы. ПКМ по ошибочному слову сохраняет меню орфографии и переход в обычное меню.
4. В «Правка → Метки реплик» отметь Forced. Скрытие столбца через заголовок не должно снимать отметку. Сохранение только Forced-реплик по-прежнему находится после «Сохранить как».
5. Проверь привычные сочетания, включая составные. Их настройки собраны в «Параметры → Клавиатура и команды». ПКМ по осциллограмме также даёт доступ к её настройкам.

## 1. Составные клавиши

**Параметры → Клавиатура и команды → Составные горячие клавиши…**. Выбери слот, задай имя и сочетание клавиш. Добавь «Вставка текста», укажи текст и `end`; затем «Поиск и замена». Сохрани, выдели реплику и нажми сочетание. Шаги должны выполняться по порядку; обычная отмена возвращает исходный текст одним действием. В списке команд доступны установленные плагины. Их отдельные сочетания по-прежнему настраиваются в **Параметры → Настройки → Горячие клавиши → Плагины**. AltGr можно назначать отдельно от левых Ctrl+Alt.

## 2. Осциллограмма

Открой видео и создай обычную форму сигнала. В **Параметры → Осциллограмма** включи «Быстрый рендерер»: расположение реплик и сигнала должно сохраниться. Там же меняется цвет сетки. Галочка «Показывать метки смены плана» скрывает светлые вертикальные линии без удаления меток; выбор сохраняется после закрытия программы. «Показывать только речь» использует отдельный кэш и отделение речи через Roformer; при первом использовании может потребоваться большая модель. Выключение возвращает обычный сигнал. Смена выбранной аудиодорожки должна использовать другой кэш. Если модель пока не нужна, достаточно проверить переключение рендерера.

## 3. Кадровое время

**Параметры → Отображение времени → Номера кадров**. Таблица и поля начала/конца должны показывать целые номера кадров, и их можно менять. Переключи обратно на миллисекунды или HH:MM:SS:FF. Для дробной частоты проверь режим «Хранить время на кадрах видео». Режим SMPTE задаётся в «Видео → Воспроизведение и панели»; он отличается от абсолютных номеров кадров.

## 4. Пакетная обработка

Открой **Инструменты → Работа с файлами → Пакетный режим…**. Сверху появились пресеты и **«Параметры 5.3…»**.

- На вкладке «Общие» задай языки, например `ru,fr`, и включи обычную операцию автоматического перевода. С уже настроенным локальным переводчиком один запуск должен создать отдельные языковые файлы. Можно выбрать формат, расширение, прошлые ошибки, форсированные дорожки, имя или код языка.
- Сохрани пресет, поменяй формат и числовой параметр, загрузи пресет: значения должны вернуться.
- На вкладке ASS/SSA при выходном формате ASS задай `FontSize=43` и `FontName=Segoe UI`, по одному свойству на строку. Можно встроить шрифты и оставить только нужные символы. В итоговом ASS должны измениться стили и появиться секция `[Fonts]`.
- На вкладке OCR задаётся соответствие `file.sup=rus`. Для других файлов остаётся общий язык OCR.
- При сохранении даты исходника выходные файлы должны иметь его время изменения.

## 5. Консольный конвертер

Открой терминал в папке сборки:

```powershell
.\seconv.exe --help-json
.\seconv.exe "C:\путь\sample.srt" ass --output-folder:"C:\путь\результат" --json
```

Должен появиться ASS и JSON-отчёт, без окна редактора. Выходные типы изображений: `imsc-image`, `bdn-image`, `bdn-8bit`, `dvd-sup`; для DVD укажи `--resolution:720x576`. Изображения сохраняются отдельной папкой. Перезапись требует `--overwrite`; исходный файл защищён от перезаписи самим собой. Современный перевод: `--translate:ollama --translate-from:en --translate-to:ru,fr`; адрес и модель переопределяются `--api-url:... --model:...`. Старые операции доступны через `--legacy` и прежние ключи `/...`. Платные провайдеры проверять не требуется.

## 6. Фоновая музыка

**Видео → Озвучка и музыка → Создать фоновую музыку…**. Без загрузки модели можно выбрать **«Открыть музыку…»**, прослушать WAV, затем **«Смешать с видео / озвучкой…»**. Если в источнике несколько аудиодорожек, появится их выбор. Выбери внешний путь результата и громкости: итог должен содержать выбранную речь и музыку. WAV-выход из видео должен содержать только звук.

Для самой генерации выбери пресет/описание, BPM, seed, вычисления и длину результата, затем «Создать и сохранить WAV…». Первый запуск скачает модель примерно 5,8 ГБ. Результат повторяется со сглаженными стыками и затуханием в конце; его длина может превышать длину генерируемого фрагмента. Новая полноценная генерация ACE-Step в автоматические проверки этой сборки не входила.

## 7. FFmpeg и дорожки

Открой видео. Выбери **Видео → Воспроизведение и панели → Плеер FFmpeg (экспериментальный)**. Проверь воспроизведение, паузу, переход по времени и покадровые команды. В **Видео → Воспроизведение и панели → Аудиодорожка FFmpeg** выбери другой язык: позиция должна сохраниться, а звук смениться. При проблемах с драйвером отключи «FFmpeg: аппаратное декодирование».

Включи **Видео → Воспроизведение и панели → Панель дорожек**. Реплики разделены по актёру и слою. Нажатие на шкалу меняет позицию; перетаскивание реплики меняет время, край — границу. Правка отменяется обычным Undo. Колесо меняет масштаб; при большом числе строк прокручивает дорожки, Ctrl+колесо меняет масштаб.

## 8. CEA-субтитры в видео

**Видео → Создать и экспортировать видео → Монтаж, перекодирование, дорожки и главы… → Дорожки → Добавить внешний файл…**. Добавь SCC и сохрани MOV: получится отдельная дорожка CEA-608. Для SCC/MCC выбери MPEG: титры встраиваются как GA94 в MPEG-2, включая CEA-708 из MCC. В этом случае видео и звук перекодируются. Физический DVD-привод для проверки файлов не нужен. При отсутствии SCC/MCC этот пункт можно пропустить; синтетические примеры уже проверены автоматически.

## 9. Зависимости

В комплект включён проверенный FFmpeg 9.0.2. Загрузчики обновлены для whisper.cpp 1.9.5, WhisperX build103 и актуального x64 MPV. Старые 32-битные/Windows 7 варианты сохранены. FFprobe поставляется отдельно. CrispEmbed GPU остаётся 0.17.11: именно такой GPU-архив использует зафиксированная исходная 5.3; 0.17.12 относится к CPU. Пользовательский VLC автоматически не заменяется.

## Границы результата

Наличие реализации и успешные проверки конкретных сценариев не означают полную сертификацию всех моделей и всех режимов 5.3. Платные API не вызывались; физический DVD, все GPU-декодеры и новое нейросетевое отделение речи/генерация музыки на больших моделях этим прогоном не проверялись. Детали по каждому блоку: [LOCAL_53_INTEGRATION.md](LOCAL_53_INTEGRATION.md).

## Плавность со спектрограммой

Открой MKV и SRT, включи спектрограмму через меню осциллограммы и проиграй несколько смен реплик. Сравни с режимом только осциллограммы. Проверь прокрутку, увеличение масштаба и изменение высоты панели: изображение должно сразу обновляться. В 4.0.27.103 масштабированный видимый участок спектрограммы кэшируется; курсор и реплики обновляются отдельно. На тестовом Crystal Lake средняя отрисовка спектрограммы снизилась с 11,6 до 1,9 мс. Это замер интерфейса, а не гарантия отсутствия всех задержек декодера или драйвера.
